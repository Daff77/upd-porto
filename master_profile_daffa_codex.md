## 6.3 CamHUB

**Kategori:** Video Management System / Camera Service Management  
**Fokus:** Pengelolaan layanan kamera dan proses backend

### Gambaran proyek

CamHUB merupakan proyek eksplorasi sistem pengelolaan kamera dan layanan video. Fokus pengembangannya adalah menyederhanakan proses menjalankan beberapa layanan kamera melalui satu alur kendali, serta menyediakan mekanisme untuk memeriksa status service yang berjalan.

Proyek ini mengeksplorasi hubungan antara aplikasi pengelola, proses backend, layanan kamera, dan port jaringan yang digunakan. Salah satu tujuan teknisnya adalah mengurangi kebutuhan menjalankan setiap komponen secara manual.

### Komponen dan kemampuan yang pernah dibahas

- **One-Click Run All:** konsep untuk menjalankan beberapa layanan kamera sekaligus.
- **Process Manager Backend:** backend menggunakan file `server.py` untuk mengelola child process pada lingkungan Windows.
- **REST API internal:** endpoint dalam kelompok `/api/services/*` untuk memeriksa atau mengelola layanan.
- **Service Monitoring:** pemeriksaan status layanan berdasarkan port, termasuk `8080`, `8081`, dan `8082` pada konfigurasi yang pernah digunakan.
- **Process Lifecycle:** eksplorasi proses menjalankan dan menghentikan layanan.
- **Configuration Files:** penggunaan file konfigurasi untuk mengatur layanan.
- **Camera/Streaming Integration:** eksplorasi integrasi dengan decoder dan layanan streaming kamera.

### Teknologi dan komponen yang pernah disebutkan

- Python untuk process manager/backend.
- REST API internal.
- Windows child process management.
- V380Decoder-Fork.
- .NET melalui penggunaan `dotnet run`.
- Port layanan yang pernah dieksplorasi, termasuk `8080` dan `8554`.

### Nilai teknis proyek

CamHUB dapat menjadi contoh eksplorasi pada sisi backend dan integrasi sistem. Proyek ini memperlihatkan minat pada pengelolaan proses aplikasi, komunikasi antarlayanan, integrasi komponen eksternal, serta otomasi operasional.

- Cara autentikasi atau keamanan API jika diterapkan.
